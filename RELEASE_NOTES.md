# langswic 1.5.5 — Windows x64

## Исправление однобуквенных слов

Автоматика больше не преобразует одиночные буквы: `я`, `Я`, `а`, `и`, `a`, `I` и другие. Защита действует и перед пунктуацией (`я,`, `я.`).

Причиной воспроизведённой ошибки было применение ранее выученного однобуквенного правила в обход обычной проверки длины слова. Теперь такие правила игнорируются при автоматической коррекции, а новые однобуквенные правила не создаются. Пользовательские данные сохраняются.

Явное ручное преобразование буквы и отмена остаются доступны.

## Установка

Скачайте **langswic-Setup.exe** из Assets и запустите его. При обновлении настройки сохраняются. Нужны Windows 10/11 x64, .NET Framework 4.8 и раскладки Russian / English (United States). Инструкция приложена в **INSTALL.md**.

Программа работает локально без аккаунта, подписки и передачи набираемого текста в сеть.

## Проверки и ограничения

Пройдены 76 проверок ядра, проверки интерфейса и интеграционные сценарии системного ввода в отдельных окнах Win32/UI Automation. Проверены одиночные буквы с искусственными правилами обучения, разный регистр и пунктуация, сохранение языка, ручная конвертация и отмена без создания нового правила. Подробные результаты — в MANUAL_TESTS.md.

Совместимость с конкретными версиями Chrome и ChatGPT требует ручного подтверждения. Установщик пока не имеет цифровой подписи; для проверки файла используйте **SHA256SUMS.txt** этого выпуска.
